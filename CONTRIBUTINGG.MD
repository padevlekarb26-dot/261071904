# Contributing to OSS-Project

Welcome! This repository is for practising the open source workflow.

## How to contribute
1. Open an issue using the "Documentation problem" template.
2. Fork this repository.
3. Create a new branch for your change (never work on main).
4. Make a small, focused change.
5. Commit with a clear message and a sign-off (git commit -s).
6. Push the branch to your fork and open a Pull Request. You may open
   it as a Draft while you are still working.
7. In the description write "Fixes #<issue number>".
8. Respond politely to review comments.

## Rules
- One Pull Request = one change.
- Do not add phone numbers, emails or other personal details.
- Read and follow the CODE_OF_CONDUCT.

Click "Commit changes" (commit directly to main). Screenshot [S8].

Step 11. Add a code of conduct. Click "Add file" -> "Create new file".
         Name: CODE_OF_CONDUCT.md. Paste:

# Code of Conduct

We want this project to be a friendly and safe place for everyone.

## What we expect
- Be polite and respectful to everyone.
- Give feedback that is specific and kind.
- Accept feedback gracefully and learn from it.

## What is not acceptable
- Insults, mocking or personal attacks.
- Spamming issues or pull requests.
- Sharing other people's private information.

## Reporting a problem
If someone behaves badly, tell the maintainer of this repository
(write a comment or contact them in class). The maintainer may
warn the person, delete the comment, or block the person from the
repository.
